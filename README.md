# MO1-Process-Multiplexer-and-CLI

OS Emulator — CSOPESY
Group members:
Cumti
Dulatre
Hong
Pineda

Requirements:
  - CMake 3.16+
  - C++17 compiler (clang++ on Mac, MSVC on Windows)

Build instructions:
  1. mkdir build && cd build
  2. cmake ..
  3. cmake --build .

Run instructions (Mac/Linux):
  ./csopesy

Run instructions (Windows):
  .\csopesy.exe
